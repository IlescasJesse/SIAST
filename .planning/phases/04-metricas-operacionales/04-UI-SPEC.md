## Spacing Scale

MUI theme spacing unit = 8px. All spacing uses theme.spacing() multiples.

| Token | Value | MUI Equivalent | Usage |
|-------|-------|----------------|-------|
| xs | 4px | spacing(0.5) | Icon gaps, badge padding, chip inner |
| sm | 8px | spacing(1) | Compact element spacing, inline gaps |
| md | 16px | spacing(2) | Default card padding, element spacing |
| lg | 24px | spacing(3) | Section padding, card content py |
| xl | 32px | spacing(4) | Layout gaps between sections |
| 2xl | 48px | spacing(6) | Major section breaks |
| 3xl | 64px | spacing(8) | Page-level top padding |

Exceptions:
- KPI stat cards: py="16px !important" (matches existing StatCard pattern in DashboardPage)
- StatCard icon box: p=1.2 (9.6px — MUI fractional, existing pattern, do not change)
- Touch targets for icon-only buttons (date filter toggle): minimum 40px (MUI default)
- Grid container spacing: spacing(2) = 16px gap between cards (existing pattern)
- Section header margin-bottom: mb(3) = 24px (existing pattern)

## Interaction Contracts

### Date Range Filter (decision D-16)

- Trigger: IconButton with TuneIcon (settings/filter icon) in section header, right-aligned
- Behavior: Popover opens below trigger with two DatePicker fields (Desde / Hasta)
- Default range: last 30 days (today - 30d to today) — decision D-05
- Apply: "Aplicar" Button (contained, primary) inside popover
- Cancel: closes popover without applying
- Applied state: IconButton shows Badge with dot (color="primary") when non-default range active
- Applies globally to all tabs simultaneously

### Tab Navigation (decision D-13, D-14)

- MUI Tabs component, variant="scrollable" scrollButtons="auto"
- Tab labels: "Global", "Por Responsable", "Por Técnico"
- indicatorColor="primary" textColor="primary"
- Tab change does NOT reset date filter
- Drill-down: click on responsable row in Global tab → switches to "Por Responsable" tab filtered to that responsable's area
- Drill-down: click on técnico row → switches to "Por Técnico" tab filtered to that técnico's ID
- Keyboard: standard MUI Tabs keyboard navigation (arrow keys, Enter)

### Real-time Updates (decision D-18, D-19)

- useEffect dependency: ticketsVersion from useNotifStore
- On version change: refetch metrics from GET /api/metricas endpoint
- No polling. No dedicated socket events.
- Loading state during refetch: Skeleton placeholders on charts, existing values remain visible (stale-while-revalidate pattern)
- Subtle indicator: LinearProgress (indeterminate, height 2px) at top of section during refetch

### Chart Interactions (Recharts defaults)

- Tooltip: active on hover, shows value + label, styled with MUI Paper background (#fff), border "1px solid rgba(0,0,0,0.08)", borderRadius 4px, font Inter 12px
- Legend: show for multi-series charts. Position: bottom. Font: caption (12px, Inter)
- ResponsiveContainer: width="100%" height={260} for bar/line charts, height={220} for pie charts
- Animation: Recharts default animation on mount. Disabled on refetch (isAnimationActive={false} when reloading)
- Bar charts: barSize={28}, gap between bars: 4px
- Line charts: strokeWidth={2}, dot={{ r: 3 }}, activeDot={{ r: 5 }}
- Pie charts: innerRadius={50} outerRadius={90} (donut style), paddingAngle={2}

### SLA Indicator

- Displayed as Chip inside KPI card and in table cells
- size="small", variant="filled"
- >= 90%: bgcolor success.main, color white, label "SLA OK"
- 70-89%: bgcolor warning.main, color white, label "En riesgo"
- < 70%: bgcolor error.main, color white, label "Incumplido"

### Efficiency Table Row Click

- Entire row is clickable (cursor: pointer, hover bgcolor PRIMARY_ALPHA(0.04))
- Click on responsable row: drill-down to Por Responsable tab
- Click on técnico row: drill-down to Por Técnico tab
- Tooltip on row: "Ver detalle de {nombre}"

### Print Mode (decision D-06)

- CSS media query @media print applied via sx prop or global styles
- Tabs hidden on print: display: none
- All tab panels visible on print (expanded, stacked vertically)
- Date filter dropdown hidden on print
- Page header shows date range as plain text
- Charts render at full width on print
- No explicit "Print" button — uses browser Ctrl+P / system print

## KPI Definitions (for executor reference)

| KPI | Formula | Display |
|-----|---------|---------|
| Total solicitudes | COUNT(tickets) en rango | Integer |
| Activos ahora | COUNT(tickets WHERE estado NOT IN RESUELTO,CANCELADO) | Integer |
| Resueltos | COUNT(tickets WHERE estado=RESUELTO) en rango | Integer |
| SLA % | COUNT(resueltos en meta) / COUNT(resueltos) * 100 | "{N}%" |
| SLA meta por categoría | TECNOLOGIAS=24h, SERVICIOS=48h, RECURSOS_MATERIALES=72h | Hardcoded backend |
| Tiempo promedio resolución | AVG(resolvedAt - createdAt) para tickets RESUELTOS | "Xh Ym" |
| Tiempo primera respuesta | AVG(primera_accion_tecnico - asignacion_ticket) | "Xh Ym" (decision D-04) |
| Ratio resuelto/cancelado | resueltos / (resueltos + cancelados) | "X:1" o "X%" |
| Índice solvencia | decision D-03 — eficiencia comparativa por nivel de rol | percentage rank |

## Implementation Notes for Executor

1. Install Recharts before implementing chart components: `npm install recharts` in apps/web/
2. DashboardPage.jsx insertion point: append MetricasOperacionalesSection after all existing role-based sections (not inside them). Section is visible for ADMIN and RESPONSABLE_* roles only.
3. Reuse StatCard and SectionCard sub-components already defined in DashboardPage.jsx. Extract to separate files if needed.
4. Date range filter: use date-fns (already installed) for date math, not dayjs. DatePicker in this section uses AdapterDateFns (not AdapterDayjs used in SolicitudNewPage) to avoid adding dayjs.
5. ResponsiveContainer from Recharts requires the parent to have an explicit height. Wrap each chart in a Box with height={260} before ResponsiveContainer.
6. All Recharts text (ticks, legend, tooltip) must use Inter font to match MUI theme: fontFamily="'Inter', 'Roboto', sans-serif".
7. Real-time: import useNotifStore, add ticketsVersion to useEffect dependencies for metrics fetch.
8. MetricasHistorial daily job: backend concern, not a frontend interaction contract item.
9. Print CSS: add @media print global styles in DashboardPage or via MUI GlobalStyles component.
10. RESPONSABLE_* areaSoporteId is available in JWT payload — no need for frontend to send it as query param.
